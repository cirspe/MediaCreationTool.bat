## Code Style
- Python for any logic involving file parsing or date arithmetic
- Shell scripts as thin wrappers only — delegate to Python for complexity
- No unnecessary abstractions; scripts do one thing each

## Workflow
- Commit messages are descriptive multi-line, ending with the session URL
- All work on feature branches (e.g. `claude/persistent-memory-system-QTwAp`)
- Push after every logical unit of work is complete and tested

## Communication
- Concise responses — lead with action, not explanation
- Use tables to summarise what was built at the end of a task
- No emojis unless requested
- Portuguese may appear ("continua") — respond in English unless directed otherwise
